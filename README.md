Учебный проект представляет собой комплексную модель корпоративной сетевой инфраструктуры, разработанную в Cisco Packet Tracer. Основная цель — отработка архитектурных решений, протоколов маршрутизации и коммутации, а также механизмов защиты.

Проект включает в себя сегментацию отделов (VLAN), динамическую маршрутизацию, базовую защиту на уровне доступа (L2 Security), симуляцию выхода в глобальную сеть (ISP) и развертывание базовых сервисов (FTP / DNS / DHCP / IP-телефония).
